정규표현식(Regular Expression)

문자열에서 특정 패던을 찾거나, 대체하거나, 나누는 도구

  • ^ : 시작, $ : 끝 - 둘 다 쓰면 처음부터 끝까지
  • \d : 숫자, \w : 영문, 숫자, _, \s : 공백 - 각 대문자는 해당하는 값들 제외
  • . : 임의으 한 문자, * : 앞 문자가 0회 이상, + : 앞 문자가 1회 이상 ? : 앞 문자가 0~1회
  • [] : 문자셋 - a~z 알파벳 소문자, A~Z 알파벳 대문자, 0~9 숫자, 가~힣 한글
  • {m} : m회, {m,n} : m~n회 반복

입력할 때마다 검사

wed Storage - 브라우저에 저장

  • sessionStorage : 그 탭을 닫으면 사라짐
  • localStorage : 브라우저를 껏다 켜도 남음(직접 지우기 전까지)
